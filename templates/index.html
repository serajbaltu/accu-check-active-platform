Install ACCU-CHEK WinUSB Driver

The Accu-Chek Active meter uses the USB Personal Healthcare Device Class (PHDC / ISO/IEEE 11073-20601). To allow modern Windows applications to read from meter memory directly at maximum speed, Microsoft's WinUSB driver must be installed.

Step 1: Launch Driver Installer

Click the button below to launch the pre-configured Zadig 2.9 utility with administrator privileges.

Step 2: Confirm and Click Install

The utility is pre-configured to detect Accu-Chek Active USB and select WinUSB. Simply click the large Install Driver (or Replace Driver) button in the pop-up window.

Step 3: Installation Complete

Within seconds, driver installation will complete and the meter connection status on this page will turn green automatically!

ACCU-CHEK Active Clock Setup Guide

Clinical Safety Guarantee: This application operates in strict Read-Only mode to protect the device's certified medical memory from alteration or corruption. Meter clock and date settings are configured directly via physical buttons on the device following these steps:

Step 1: Enter Set-up Mode

Ensure the meter is turned off and unplugged from the USB cable. Press and hold the S button (on the front/side of the meter) for more than 2 seconds until Set-up appears on screen and the time format (24h/12h) blinks.

Step 2: Adjust Values Using Physical Buttons

• Press M to increment or change the selected value.
• Press S to save the value and advance to the next field (Hours → Minutes → Year → Month → Day).

Step 3: Save and Exit

After confirming the day, press both S and M buttons simultaneously to save all settings and turn off the device.
